# AbdCompressTools
<img width="1254" height="1254" alt="image" src="https://github.com/user-attachments/assets/b2b510c2-3c22-474d-84f2-e8600daa087b" />


Fast PDF management for all platforms. View, convert, compress, merge, split,
and digitally sign PDFs.

**Flutter 3.10.7+ | Dart | 50+ formats | 6 platforms**

## Features

- Viewer - View standard and password-protected PDFs
- Compress - Reduce file size
- Image to PDF - JPG, PNG, WEBP, HEIC, TIFF, GIF, BMP
- Convert - Export and create PDFs
- Edit - Add text and annotations
- Merge - Combine PDFs
- Split - Extract pages
- Sign - Digital signatures
- History - Recent files and favorites

## Platforms

| Android | iOS | macOS | Linux | Windows | Web |
|---------|-----|-------|-------|---------|-----|
| Yes | Yes | Yes | Yes | Yes | Yes |

## Quick Start

```bash
flutter pub get
flutter run
```

## Build

```bash
# Android
flutter build apk --release

# iOS
flutter build ios --release

# Desktop
flutter build linux --release
flutter build windows --release
flutter build macos --release

# Web
flutter build web --release
```
